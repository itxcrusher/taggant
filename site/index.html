365 nmmove the lamp over the carton

A filtered 365 nm head emits about 8.6 lux of visible light, so the field reads black rather than violet, and the substrate is specified UV dull. Blue-white is the documented failure state, not a feature. Fluorescence stops the moment the beam leaves. The sources for all of that name the fluorescence colours and never publish values, so the colours here are an interpretation and are said to be one.

A reader for printed things.

Recognise printed artwork through a phone camera, resolve the code on a product to the right destination for as long as that product exists, and publish every experience as a folder that keeps working when the servers are gone.

What it does

Recognises printed artwork

Point a phone at a pack, a label, a poster or a print and content anchors to it in the browser, with nothing to install. The detector, the descriptor, the matcher and the pose solver are all in the repository and carry no dependencies.

Resolves printed codes

An implementation of GS1 Digital Link, so one code can serve different content across a product's life without reprinting. The link table is plain JSON that can be read out and rehosted anywhere.

Judges artwork before press

A press run cannot be undone, so the compiler answers first: how much there is to track, whether the artwork repeats itself, and the smallest width it can be printed at and still be read from a stated distance.

Publishes standalone bundles

An experience compiles to a static folder carrying its own runtime and assets. A test serves that folder alone and fails on any request that leaves the origin.

What it guarantees

  • C-01A published experience carries its own runtime and assets and never calls this project to work.
  • C-02The manifest format is open, versioned and documented, so anything else can read or write it. A manifest is data: it cannot carry a script destination.
  • C-03Resolver conformance is tested criterion by criterion against the criteria GS1 publishes, with each test named for the requirement it checks, on every push.
  • C-04Image targets first, because handheld web AR has no camera pose on every platform and printed artwork is the trigger that works everywhere.
  • C-05No proprietary runtime dependency that cannot be redistributed.

What has and has not been verified

The runtime is driven in a real browser against a synthetic camera, and a published bundle is driven the same way from a static folder with every service switched off. Descriptors are compared across engines, because the compiler runs in Node and the runtime runs in a browser and the whole thing rests on them agreeing.

Not verified: any real camera, and any real print. Everything above is synthetic. The device matrix is empty and stays empty until it can be filled in with measurements, and the camera resolving power the print report assumes is an assumption until then.
